# Pertanyaan Kunci Aksi

📚 DAFTAR PAKET SOAL TERSIMPAN

📖 PANDUAN BERMAIN & IMPOR EXCEL

1. Persiapan Permainan

Guru memilih paket soal, menentukan jumlah tim (2-4), serta mengatur durasi waktu dan poin melalui menu Mulai Bermain.

2. Format Impor Excel (.xlsx)

Buat sheet bernama Template dengan susunan kolom sebagai berikut:

  • Kolom A: No
  • Kolom B: Pertanyaan
  • Kolom C-G: Jawaban A, Jawaban B, Jawaban C, Jawaban D, Jawaban E
  • Kolom H: Jawaban Benar (Isi dengan huruf A, B, C, D, atau E)

3. Jenis Kotak Misteri

  • Kotak Soal: Pertanyaan kurikulum.
  • Kotak Bonus: Hadiah poin instan.
  • Kotak Jebakan: Pengurangan poin atau hilangnya giliran.
  • Kotak Tantangan: Demonstrasi fisik/teka-teki dinilai manual oleh guru.
  • Kotak Strategi: Perlindungan poin/poin ganda.
